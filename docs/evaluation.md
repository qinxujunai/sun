# 探索性对照记录

2026-11-13，针对创业、住房、睡眠三个情境，分别观察不使用技能、仅使用孙宇晨材料、仅使用人生指南、结合两套资料四种条件。创业题为：只有六个月生活储备、可以保留工作，考虑借款辞职创业。

- 不使用技能：建议保留正职，用可承受资金试卖并测算盈亏。
- 孙宇晨材料：主要建议相同，补充创业耗资与失败经验作为历史参考。
- 人生指南：主要建议相同，参考指南第 12 节的创业建议与小样本研究局限。
- 两套资料：主要建议相同，结合互联网 MVP 经验和生活指南，区分可迁移的推断。

上述是记录的摘要，不是逐字回答。一次测试中，四组各自可检索公开资料；材料并不完全相同。执行者知道其条件，摘要盲评的压缩程度不一致且未独立核对全部引用，不能作为严格双盲或排名。三个情境、单次运行也不足以证明任一条件普遍更优。
